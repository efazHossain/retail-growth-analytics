# Notebook Workspace

This folder is reserved for exploratory notebooks.

Suggested notebook ideas:

- `01_mart_profiling.ipynb`: review row counts, missing values, and distributions
- `02_customer_segmentation.ipynb`: explore customer value tiers and repeat behavior
- `03_forecast_backtest.ipynb`: compare simple revenue forecasts against actuals

The Python scripts in `python/retail_growth_analytics/` are written so notebook work can import reusable logic instead of copying code into cells.
